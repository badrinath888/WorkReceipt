Getting Started

What is WorkReceipt?

WorkReceipt is a Mac app that reads your Claude Code session history and the Git history of a project you choose, then writes a client-readable work report. The report keeps three things apart: work requested (from your prompts), changes delivered (from Git commits) and checks that were recorded. You edit the wording, review privacy findings, and export HTML or PDF.

Who is it designed for?

Freelance developers and small software agencies who build with Claude Code and need to show clients what was asked for and what was delivered, without handing over raw session logs.

What do I need to get started?

A Mac, Claude Code session history on that Mac, and a project that is a Git repository with commits in the period you want to report on. WorkReceipt is in private beta, so there is no public download yet.

Compatibility

Which Macs are supported?

The current private-beta build is made for Apple silicon Macs. The minimum macOS version and whether Intel Macs will be supported have not been decided, and will be confirmed before any public release. Windows and Linux are not targets.

Do I need Claude Code?

Yes. The work requests in a report come from the Claude Code session logs that Claude Code stores on your Mac. Claude Code does not need to be running while you use WorkReceipt.

Is Git required?

Yes. Git history is the evidence for delivered changes, so the project should be a Git repository with commits in the reporting period. Only the current branch is read.

Privacy

Does WorkReceipt upload my data?

No upload is required. Your sessions and repositories are read and processed on your Mac, there is no account, and nothing is sent to a WorkReceipt server to generate a report. Reports are saved to a folder on your Mac.

What information appears in a report?

Prompt titles (the first line of each prompt), the commands of recorded checks, commit subjects and folder names. File contents and tool output are never included.

How does redaction work?

WorkReceipt masks common secret and personal-data patterns, such as keys, tokens, email addresses and file paths, and lists each masked value in the Privacy Center by severity. Every high-severity finding needs your review before export unlocks, and you can add your own terms, such as a client name, to mask everywhere. Redaction is best-effort: it does not catch everything, so read your report before you send it.

Reports

What can I edit?

The wording of each work request in Report Studio, so technical prompts can become plain language. Edits are re-checked for secrets before they reach the report.

How accurate are the reports?

The report keeps requests, Git-backed changes and recorded checks separate. It never says a request was completed, since a request is not proof of completion, and recorded checks are not re-run. Check detection covers common test and build runners rather than every custom script, so review each report before you send it.

Can I export HTML and PDF?

Yes. WorkReceipt exports a standalone HTML report and a PDF.

Pricing and Updates

Is WorkReceipt free or paid?

Not decided yet. We plan an affordable license for freelance developers and small agencies. The price and terms will be published before any public release, and nothing can be bought today.

How are updates delivered?

The current private-beta build is updated by installing a newer version over the old one. How updates will be delivered for a public release has not been decided.
